# Mandatory Frontend Workflow

Before editing, identify:

- user role;
- user goal and next expected step;
- affected BPMN process;
- affected route and permissions;
- requirement IDs;
- existing components and API contracts;
- responsive and accessibility implications.

Create a plan before implementation. Finish one coherent vertical slice. Update the implementation matrix and evidence in the same change. Invoke the read-only `ui-ux-reviewer` before completion.
