# UI/UX Review Schema

## Decision

`PASS`, `PASS WITH OBSERVATIONS`, or `BLOCKED`

## Requirement traceability

List each affected requirement ID and evidence.

## Blocking findings

For every blocker include:

- requirement or rule;
- affected file/screen;
- observed problem;
- expected correction.

## Non-blocking observations

Limit to concrete improvements, not personal taste.

## Verification gaps

List missing viewport, state, keyboard, localization, test, or screenshot evidence.
