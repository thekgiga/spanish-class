# Responsive Checklist

Verify at 390, 768, 1280, and 1440 CSS pixels.

- Navigation model is appropriate.
- Primary action remains visible and reachable.
- Overlays become drawers/sheets appropriately.
- No accidental horizontal overflow.
- Calendar interaction has a mobile alternative.
- Text does not truncate essential meaning.
- Touch targets are at least 44x44.
- Keyboard order remains logical on desktop.
