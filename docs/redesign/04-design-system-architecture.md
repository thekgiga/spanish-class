# Design-System Architecture

## Layer 1 — Foundations

Semantic color, type, spacing, radius, border, elevation, motion, breakpoint, layout, and z-index tokens.

## Layer 2 — Primitives

Button, icon button, input, textarea, select, checkbox, radio, switch, tabs, badge, avatar, tooltip, separator, skeleton, and spinner.

## Layer 3 — Shared composites

Page header, app sidebar, mobile navigation, right drawer, mobile sheet, confirmation dialog, search command, empty state, status badge, user summary, date/time summary, notification item, form section, and settings card.

## Layer 4 — Domain components

Calendar event, selection composer, booking request card, lesson card, available-time card, approval actions, student summary, lesson timeline, attendance control, and recurrence composer.

## Layer 5 — Page templates

Calendar workspace, two-panel booking, directory/details, settings, authentication, and state/empty page templates.

## Central domain mapping

Booking state must map in one place to:

- user-facing label;
- icon;
- semantic tone;
- emphasis;
- allowed actions;
- calendar visibility;
- history visibility.
