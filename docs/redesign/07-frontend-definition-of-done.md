# Frontend Definition of Done

A frontend change is done only when:

- affected requirement IDs are identified and updated;
- BPMN behavior and role permissions remain correct;
- existing tokens and components are reused;
- no new raw palette or arbitrary styling is introduced;
- default, loading, empty, error, disabled, success, and conflict states are covered where relevant;
- English, Serbian, and Spanish strings are complete;
- desktop, tablet, and mobile behavior is verified;
- keyboard, focus, semantics, contrast, and reduced motion are verified;
- typecheck, lint, build, guardrails, and relevant tests pass;
- E2E coverage exists for critical user-flow changes;
- visual evidence exists;
- the independent UI/UX reviewer has no blockers;
- remaining limitations are documented.

A statement from the implementation model is not evidence.
