# Spanish Class UI/UX Redesign

This directory is the executable redesign ledger.

- `current-phase.md` tells Claude where to continue.
- `implementation-matrix.csv` is the requirement-level source of progress.
- numbered documents define the approved system.
- `evidence/` proves individual changes.
- `decisions/` records product decisions that must not be silently reversed.

The BPMN documentation in `docs/product/processes-overview.md` is the functional source of truth. UX simplification must not remove backend lifecycle behavior without an explicit ADR and corresponding tests.
