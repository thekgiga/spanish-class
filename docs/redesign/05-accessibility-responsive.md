# Accessibility and Responsive Contract

## Accessibility baseline

- keyboard parity;
- visible focus;
- semantic structure;
- associated labels/errors;
- status not color-only;
- meaningful async announcements;
- focus containment and restoration;
- 44px mobile touch targets;
- reduced-motion support;
- non-pointer calendar alternative.

## Viewport contract

- 390px: mobile interaction model;
- 768px: tablet transition;
- 1280px: standard desktop;
- 1440px: large desktop density.

Desktop, tablet, and mobile evidence is required for changed critical flows.
