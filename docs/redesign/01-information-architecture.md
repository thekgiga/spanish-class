# Information Architecture

## Professor

1. Schedule
2. Students
3. Insights
4. Settings

Schedule absorbs the daily purpose of the old dashboard, availability, calendar, and pending-approval destinations. Email logs and security belong under Settings.

## Student

1. Home
2. Book a Lesson
3. My Lessons
4. Profile

Referrals belong within Profile or a contextual card, not permanent primary navigation.

## Route-change rule

Every route migration must document:

- old route;
- new route;
- redirect strategy;
- role guard;
- deep-link behavior;
- navigation placement;
- analytics/test impact.
