# Visual North Star — Editorial Teaching Studio

## Product character

Spanish Class is a focused teaching workspace, not a generic school ERP and not a colorful consumer-learning game.

The interface must feel:

- calm and precise;
- personal without being childish;
- warm without becoming decorative;
- premium through proportion and restraint, not gradients and glow;
- fast enough for daily professional use;
- clear enough for a student using it for the first time.

## Creative direction

Combine four qualities:

1. **Editorial warmth** — ivory canvas, strong typography, tasteful terracotta accents.
2. **Productivity clarity** — compact controls, predictable drawers, keyboard support, high information signal.
3. **Calendar confidence** — time is the dominant organizing structure for the professor.
4. **Human teaching context** — student names, next actions, and lesson state are more prominent than system entities.

## Signature visual moments

- The professor Schedule page is the reference surface.
- Calendar selection has a soft tinted preview with live time and duration.
- Pending requests are warm amber and action-oriented, never alarming.
- Confirmed lessons use deep ink green, creating a distinctive weekly rhythm.
- Student booking uses a quiet two-panel date/time composition, not an admin calendar.
- Drawers preserve context and feel like a natural extension of the current page.

## What “premium” means here

Premium means:

- fewer, better surfaces;
- excellent alignment;
- intentional whitespace;
- stable interaction behavior;
- precise typography and numeric rendering;
- restrained use of color;
- meaningful motion;
- polished empty, loading, error, and success states.

Premium does **not** mean:

- glassmorphism everywhere;
- neon gradients;
- oversized rounded cards;
- glow effects;
- decorative illustrations on operational screens;
- excessive animations;
- every element floating in its own container.
